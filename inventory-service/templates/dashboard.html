Conectar Microsoft Entra ID

Lectura de usuarios, aplicaciones empresariales y permisos OAuth

Cómo obtener estos datos (5 minutos, requiere un administrador de Entra ID)
  1. En el Microsoft Entra admin center, ve a Applications → App registrations → New registration y créala con el nombre «IdentityHub».
  2. En API permissions, agrega Microsoft Graph → Application permissions → User.Read.All, Application.Read.All y DelegatedPermissionGrant.Read.All, y pulsa Grant admin consent. Son de solo lectura.
  3. En Certificates & secrets, crea un client secret y copia su Value (solo se muestra una vez).
  4. En Overview, copia el Directory (tenant) ID y el Application (client) ID.
Cómo obtener estos datos (3 minutos, en la consola de Keycloak)
  1. Entra a la consola de administración (/admin) y elige el realm de tus usuarios.
  2. Clients → Create client: Client ID identityhub-inventario. En el siguiente paso activa Client authentication y Service accounts roles, y desactiva Standard flow.
  3. En la pestaña Service accounts roles → Assign role → Filter by clients, asigna view-users y manage-users de realm-management.
  4. En la pestaña Credentials, copia el Client secret.
